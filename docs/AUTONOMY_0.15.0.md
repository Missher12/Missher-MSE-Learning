# 0.15.0 精简重建与迁移

> 0.16.0-rc.1 起：学习库格式为 4（仍只读兼容 format3，首次真实写原子迁移）；每条经验有当前版窗口并与家族累计分开，失败版只作 guard 警示，新增有界 `methodHistory`（≤128 条/每条 ≤6144 UTF-8 字节，总 2 MiB 不变）。迁移细节与只读召回回放见 README 的「0.16.0 系列迁移历史（始于 rc.1）」段。本文件的 0.15 运行、边界与安装说明继续适用。


本地候选版本为 0.15.0-rebuild.23（历史记录，非当前版本），未发布。用户已授权审查通过后安装；实际安装结果另见交付回执。

主链为全局纠错/真实失败记录 → 具体办法 → 相关任务召回 → 结果回写 → 复发修订；每天本地23:00后空闲汇总。新运行闭包为 rebuild/、必要纯辅助模块和宿主用量解析，不加载旧9000行核心及多阶段评测/合并/续期链。

明确用户规则长期保存，通用规则全局可见，项目限制保留；不要再/别再等否定词保留。两次独立真实失败才进入自动失败复盘，重复事件不凑次数。原因推测、具体步骤与检查一起存储，未验证不伪装可信方法。同轮去重、后续相关回合可再带出，默认最多两条/768B经验正文。

rebuild.7 支持普通纠正，不再要求“记住”。疑似纠正与紧邻助手上下文一起进入来源绑定的后台提取，先持久审计、每回合最多一个任务和两条规则；只调用原学习模型路线，沿用暂停与 reflectionEnabled，不对每轮聊天无条件分类。明确的直接规则仍即时保存；普通规则在回合结束后的空闲机会落库，待处理与忽略原因可查。技术内联命令保留，引用日志不走即时入库；一次性与不确定意图不因项目范围而升级为长期。memory 格式3缺少新 corrections 表时默认补空表，原记录不丢。语义识别及保守提交校验有覆盖边界，不能保证任意表达都识别成功。

结果区分verified/failed/cancelled/unknown并有证据摘要；目前自动产物检查覆盖项目JSON解析。复发依实际注入版本和失败上下文归因，取消不记复发。旧办法和新证据进入修订，实质没有变化不重置复发。模型文字不验证任务，单次检查通过不自授validated。

来源回合的provider/model与任务绑定，不借其他项目的路线。自动复盘与每日总结沿用enabled/reflectionEnabled，暂停持久化；费用未知不自动重放，已知截断最多一次有审计重试。删除每日预算不是免费调用承诺，后台模型仍可能产生费用。

旧lessons-v1.json保持原字节，新memory-v1.json单独保存精简库。启动只读幂等导入规则/符合条件的经验，保留原条件和历史来源；旧问题、spends、budgetEntries等原记录仍在原库，不清空、不伪造新验证。安装前备份旧包、目标配置与整个学习目录。回退使用备份和原宿主安装方式，不拿旧快照覆盖新增事实。

离线已演示跨项目纠错、真实JSON失败与修订、原生形状的结果回收、每日去重/补做、暂停/来源/截断和未知费用；真实provider长期效果、多会话压力与全部自然语言表达未验证。不保证模型永不犯错。

rebuild.20 集中修复：停用授权按引用感知的完整命令语境核验，不从条件/否定/日志/界面文案中截出命令；普通纠正的替换只有合格新规则实际保存后才同事务退役旧版。新可选 action/intentEvidence 字段兼容缺失的旧记录，但不补造授权。超长或不确定授权保留可读原因。字段生产与校验统一 UTF-16 单位并保留原上限，学习库不可读写时普通前台步骤继续。后台提取首试 1024，已知截断唯一重试 4096；未知费用不重放。

本轮已测的已知反例与当前假 provider 套件均通过；2 MiB 容量拒绝仍仅源码核对，未动态触达。复杂或跨句授权语义不能保证识别；不确定时应先查看候选审计。纯对话可为 unknown 并带真实 evidenceHash，不冒充 verified。旧库不批量清理；旧误停记录保留，重新确认正确规则走自然纠正保存新条目。

rebuild.21 修复反思产物与日总结：反思、修订、日总结单次输出上限4096 tokens，已知费用的截断或字段过长允许同材料唯一压缩重试，当前路径不再受固定30分钟复盘冷却阻挡。每日事实每批64条，以完整事实身份去重；暂拒来源恢复可补做，旧失败证据缺不可变来源时只保留历史，不借新来源回放。日总结忠实链接有效用户规则，新的具体失败方法必须经过同一结构化教训校验，并带问题、证据、项目与环境绑定，进入召回、复发和修订链；临时任务、停用规则、反转否定和未发送证据不能借总结生成新全局规则。

新增来源、身份账与诊断字段均为可选兼容字段；保留旧库全部历史、原模型路线、开关和23:00时间。新库写入这些字段后回退旧包应先停用，保留完整新增数据，不用备份覆盖新增事实。真实安装与受控失败/日总结演示以单独交付记录为准。

rebuild.22 将诊断回收接到原生会话事件流：仅同会话、同回合、已观察开始后的最后一条合格助手报告可成为未验证线索，首写冻结、结束后清理；取消、跨回合、来源撤回和外部材料不串入。正常代码围栏仅作格式中和，正文仍完整通过权限/敏感检查，最终保留最多512个UTF-16单位且1024 UTF-8字节的尾段。该报告不授予verified或validated。

真实4096 tokens修订曾连续达到生成上限却未收到正文；本版只将反思/修订的生成上限增至8192 tokens，最终JSON≤4096字节及原有教训校验不放宽。日总结与普通纠正的生成策略、provider/model/思考强度不改。生成上限或system提示变化不会解锁旧材料，真实新增诊断才构成新增事实。生成达到上限且无正文按可观察事实显示，推理量不可得时保持null。

rebuild.23 仅统一设置入口显示名为「自我进化」（英文 Self-evolution），不改学习开关、模型路线与汇总时点。
